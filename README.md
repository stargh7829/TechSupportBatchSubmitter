# 技术支持批量提交工具

面向目标技术支持系统的 Windows 批量提交、查询和关贴工具。程序读取技术支持
Excel 清单，在用户登录的业务工作台/技术支持系统会话中创建工单；创建核验成功后，
立即执行“受理并处理”并回读结果。

## 已实现

- 识别唯一包含模板表头的工作表。
- 首次读取时在 Excel 同目录创建时间戳备份。
- 识别导入模板末尾的 `处理类型` 字段（填写 `运营` 或 `运维`），并将该值随工单提交；旧模板自动补齐为 `运营`。
- 读取每行必填的 `处理说明`，在事件申请创建核验成功后立即写入“受理并处理”页面。
- 追加并维护 `技术支持编号、提交状态、实际提交时间、失败原因、受理并处理状态、受理并处理完成时间、受理并处理失败原因、关闭状态、实际关闭时间、关闭失败原因`。
- 为表头和全部使用区域添加可见边框。
- 已有技术支持编号的行自动跳过。
- 动态解析人员、事件类型和所属系统的平台 ID。
- 第一条立即提交，之后默认随机等待 30-90 秒；界面可填写固定秒数覆盖默认区间。
- SQLite 保存候选编号、行指纹和提交状态，支持崩溃恢复。
- 保存结果不确定时保留旧编号并标记为 `待核验`，不会换号重复提交。
- 受理并处理结果不确定时保留原编号并标记为待核验，不会自动重复受理；明确失败的记录可在下一次运行时仅补做该步骤。
- 登录失效、平台协议异常或 Excel 无法写入时暂停队列。
- 支持仅重试失败项。
- 选择 Excel 后自动读取并创建备份，开始提交时自动执行平台预检。
- 选择 Excel 后输出模板校验摘要，并把明显问题行标记为 `校验失败`。
- 支持导出脱敏诊断包，便于反馈运行环境和错误日志。
- 诊断包包含程序版本、运行环境、配置摘要、模板校验摘要和脱敏日志。
- 左侧登录页面支持拖动调宽及一键放大/恢复。
- 左侧登录页面支持一键最小化为“恢复页面”窄条。
- 界面采用猫系浅色主题，统一按钮、输入框、表格和提示框样式。
- 非全屏窗口下右侧工作区支持横向/纵向滚动，避免查询条件和操作按钮被裁掉。
- 待受理查询和提交清单关闭的单条“关闭”按钮放在编号/标题旁边，不再藏在表格最右侧。
- 对目标工作台和技术支持系统两个固定地址自动处理内部证书错误。
- 支持按事件标题查询“待受理事项 - 未受理”记录，更多条件默认折叠，需要时展开。
- 待受理查询支持表头全选、单行关闭和仅处理勾选项的批量关闭。
- 待受理查询结果不显示无业务用途的 Jira 编号和 Jira 状态。
- 支持按当前 Excel 提交清单关闭已生成编号的技术支持单，关闭结果回写同一 Excel。
- 本地保存提交历史和关闭历史，可用于后续关联自动提交的技术支持单。
- “关闭”默认按内置回复执行“受理并总结”，也可在关闭页展开“自定义回复”临时调整口径。
- 批量关闭第一条立即执行，之后默认随机等待 5-10 秒；界面可填写固定秒数覆盖默认区间。
- 关闭结果不明确时标记为待核验并暂停，不会自动重复关闭。

## 使用流程

1. 启动 `TechSupportBatchSubmitter.exe`。
2. 在左侧登录页面完成业务系统登录，并进入技术支持系统。
3. 点击“选择并读取”选择 `.xlsx` 清单，程序自动读取并创建备份。
4. 填写每行的“处理说明”，点击“开始提交”；程序先自动预检，再显示真实提交确认框。
5. 运行期间不要使用 Excel 打开或修改同一个清单。

待受理关闭：

1. 切换到“待受理查询”，默认按事件标题查询，需要时点击“更多条件”展开扩展项。
2. 单条点击行内“关闭”，或勾选记录后点击“批量关闭”。
3. 默认确认内置回复字段后执行；批量关闭每条核验后按当前关贴间隔等待。
4. 需要特殊口径时点击“自定义回复”展开配置区，选择原因分类树并填写原因描述、
   解决方法和解决方案；未展开时仍使用默认回复。

提交清单关闭：

1. 在“批量提交”页选择 Excel 清单。
2. 切换到“提交清单关闭”，点击“查询清单”，程序按已回填的技术支持编号生成关闭列表。
3. 单条关闭或勾选后批量关闭；默认使用内置回复，打开“自定义回复”后使用本页设置。
4. 成功、失败和待核验结果会回写 Excel。

历史记录：

1. 切换到“历史记录”查看本机提交历史和关闭历史。
2. 历史保存在 `%LocalAppData%\TechSupportBatchSubmitter\recovery.db`。

程序数据位于：

`%LocalAppData%\TechSupportBatchSubmitter`

其中包含 WebView2 用户数据、恢复/历史数据库、脱敏日志和 `settings.json`。
程序不在日志中记录工单描述、密码、Cookie、手机号或身份证号。

`settings.json` 首次启动自动生成，可配置：

- `WorkbenchUrl`：左侧工作台默认地址。
- `SupportPlatformUrl`：技术支持系统默认地址。
- `DefaultSubmissionDelayMinSeconds` / `DefaultSubmissionDelayMaxSeconds`：提交默认随机间隔。
- `DefaultCloseDelayMinSeconds` / `DefaultCloseDelayMaxSeconds`：关闭默认随机间隔。
- `VersionNoticeUrl`：可选版本提示 JSON 地址。
- `LatestVersion` / `ReleaseNotes`：没有远程地址时可用的本地版本提示。

## 开发与测试

仓库使用 `global.json` 固定 .NET SDK `8.0.422`。本机仓库内 SDK 路径为：

`D:\技术支持提交codex\.tools\dotnet\dotnet.exe`

```powershell
& ".tools\dotnet\dotnet.exe" test TechSupportBatchSubmitter.sln
& ".tools\dotnet\dotnet.exe" build TechSupportBatchSubmitter.sln
```

生成便携包：

```powershell
pwsh -File .\scripts\build-portable.ps1
```

## 维护边界

平台未提供正式开放 API。当前适配器调用网页自身请求，平台页面、字段名、端点或返回
结构变化后，需要更新 `WebViewTicketPlatformClient`。当前版本不处理附件、所属模块
自定义和平台独立的二次关闭步骤。
