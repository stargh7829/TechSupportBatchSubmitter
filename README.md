# 技术支持批量提交工具

基于 `.NET 8 WPF + WebView2` 的 Windows x64 批量提交程序。程序读取技术支持
Excel 清单，在用户登录的官方杭州人社工作台/技术支持平台会话中创建工单，并在
核验成功后立即回写技术支持编号。

## 已实现

- 识别唯一包含模板表头的工作表。
- 首次读取时在 Excel 同目录创建时间戳备份。
- 追加并维护 `技术支持编号、提交状态、实际提交时间、失败原因、关闭状态、实际关闭时间、关闭失败原因` 七列。
- 为表头和全部使用区域添加可见边框。
- 已有技术支持编号的行自动跳过。
- 动态解析人员、事件类型和所属系统的平台 ID。
- 第一条立即提交，之后默认随机等待 30-90 秒；界面可填写固定秒数覆盖默认区间。
- SQLite 保存候选编号、行指纹和提交状态，支持崩溃恢复。
- 保存结果不确定时保留旧编号并标记为 `待核验`，不会换号重复提交。
- 登录失效、平台协议异常或 Excel 无法写入时暂停队列。
- 支持仅重试失败项。
- 选择 Excel 后自动读取并创建备份，开始提交时自动执行平台预检。
- 左侧官方页面支持拖动调宽及一键放大/恢复。
- 左侧官方页面支持一键最小化为“恢复页面”窄条。
- 界面采用猫系浅色主题，统一按钮、输入框、表格和提示框样式。
- 对工作台和技术支持平台两个固定地址自动处理内部证书错误。
- 支持按事件标题查询“待受理事项 - 未受理”记录，更多条件默认折叠，需要时展开。
- 待受理查询支持表头全选、单行关闭和仅处理勾选项的批量关闭。
- 待受理查询结果不显示无业务用途的 Jira 编号和 Jira 状态。
- 支持按当前 Excel 提交清单关闭已生成编号的技术支持单，关闭结果回写同一 Excel。
- 本地保存提交历史和关闭历史，可用于后续关联自动提交的技术支持单。
- “关闭”按固定字段执行“受理并总结”，核验进入 `已解决` 后视为成功。
- 批量关闭第一条立即执行，之后默认随机等待 5-10 秒；界面可填写固定秒数覆盖默认区间。
- 关闭结果不明确时标记为待核验并暂停，不会自动重复关闭。

## 使用流程

1. 启动 `TechSupportBatchSubmitter.exe`。
2. 在左侧官方页面登录杭州人社工作台，并进入技术支持平台。
3. 点击“选择并读取”选择 `.xlsx` 清单，程序自动读取并创建备份。
4. 点击“开始提交”，程序先自动预检，再显示真实提交确认框。
5. 运行期间不要使用 Excel 打开或修改同一个清单。

待受理关闭：

1. 切换到“待受理查询”，默认按事件标题查询，需要时点击“更多条件”展开扩展项。
2. 单条点击行内“关闭”，或勾选记录后点击“批量关闭”。
3. 确认固定字段后执行；批量关闭每条核验后按当前关贴间隔等待。

提交清单关闭：

1. 在“批量提交”页选择 Excel 清单。
2. 切换到“提交清单关闭”，点击“查询清单”，程序按已回填的技术支持编号生成关闭列表。
3. 单条关闭或勾选后批量关闭；成功、失败和待核验结果会回写 Excel。

历史记录：

1. 切换到“历史记录”查看本机提交历史和关闭历史。
2. 历史保存在 `%LocalAppData%\TechSupportBatchSubmitter\recovery.db`。

程序数据位于：

`%LocalAppData%\TechSupportBatchSubmitter`

其中包含 WebView2 用户数据、恢复/历史数据库和脱敏日志。程序不在日志中记录工单描述、
密码、Cookie、手机号或身份证号。

## 开发与测试

仓库使用 `global.json` 固定 .NET SDK `8.0.422`。本机仓库内 SDK 路径为：

`D:\技术支持提交codex\.tools\dotnet\dotnet.exe`

```powershell
& ".tools\dotnet\dotnet.exe" test TechSupportBatchSubmitter.sln
& ".tools\dotnet\dotnet.exe" build TechSupportBatchSubmitter.sln
```

生成便携包：

```powershell
pwsh -File .\scripts\build-portable.ps1
```

## 维护边界

平台未提供正式开放 API。当前适配器调用网页自身请求，平台页面、字段名、端点或返回
结构变化后，需要更新 `WebViewTicketPlatformClient`。当前版本不处理附件、所属模块
自定义和平台独立的二次关闭步骤。
