技术支持批量提交工具 1.4.0
========================

一、启动
双击 TechSupportBatchSubmitter.exe。
本程序已包含 .NET 8 运行环境，无需另装 .NET。
本版界面采用猫系浅色主题，按钮、表格、输入框和提示框已统一为产品化样式。
非全屏窗口下，右侧工作区支持横向和纵向滚动，避免查询条件或操作按钮被裁掉。

二、登录
在左侧业务系统登录页面完成登录，并进入技术支持系统。
程序不提供模拟登录页，不保存账号密码。

三、提交
1. 点击“选择并读取”选择技术支持 Excel 清单，程序会自动读取并创建备份。
2. 查看模板校验摘要；如有“校验失败”，修正 Excel 后重新选择文件。
3. 点击“开始提交”，程序会自动校验平台字段。
4. 确认后第一条立即提交，之后默认随机等待 30-90 秒；如填写“提交间隔”秒数，则固定按该秒数等待。

四、待受理查询
切换到“待受理查询”页签，可按事件标题查询“待受理事项 - 未受理”记录。
其他查询条件默认折叠，点击“更多条件”后可按编号、类型、系统、人员、时间等扩展项查询。
选择列表头提供“全选/取消全选”。单行“关闭”只处理当前行；“批量关闭”只处理
已勾选记录，第一条立即执行，之后默认随机等待 5-10 秒；如填写“关贴间隔”秒数，则固定按该秒数等待。
关闭固定执行“受理并总结”：原因分类=数据疑问、原因描述=已处理、
解决方法=修改数据、解决方案=已处理；事件描述保持页面默认引用值，不支持自定义。
工单核验进入“已解决”后视为成功，不执行平台独立的二次关闭步骤。

五、提交清单关闭
切换到“提交清单关闭”页签，程序会按当前 Excel 中已回填“技术支持编号”的行生成
关闭列表；如未显示记录，点击“查询清单”重新按当前 Excel 生成。单条关闭或勾选后批量关闭的规则与“待受理查询”一致。
单条“关闭”按钮放在编号和标题附近，不需要拖到表格最右侧查找。
关闭结果会回写到同一个 Excel 的“关闭状态、实际关闭时间、关闭失败原因”三列。
如果 Excel 被占用，平台关闭结果仍以页面核验为准，程序会提示关闭 Excel 后重新核对。

六、历史记录
切换到“历史记录”页签，可查看本机提交历史和关闭历史。
历史保存在 recovery.db 中，包含编号、标题、状态、Excel 行号、来源和处理结果。
历史不保存事件描述、密码、Cookie、身份证号或手机号。

七、断点恢复
程序会在本机保存恢复数据库。重启后重新选择同一 Excel 并校验，程序会优先核验
上次保留的候选编号，避免重复提交。

八、注意事项
- 提交期间不要用 Excel 打开或修改同一个文件。
- Excel 原文件同目录会生成时间戳备份。
- 已填写“技术支持编号”的行会直接跳过。
- “待核验”记录不会自动换新编号重新提交。
- 登录失效、网络整体异常或 Excel 无法写入时队列会暂停。
- 关闭保存结果不明确时会暂停，必须先在平台人工核验，程序不会自动重复关闭。
- 当前版本不处理附件或平台独立的二次关闭步骤。

九、页面显示与证书
左侧登录页面和右侧工作区之间的分隔条可以拖动。
点击“放大页面”可让登录页面占满工作区，再点击“恢复布局”缩回。
点击“最小化”可将左侧登录页面完全收起，仅保留“恢复页面”窄条。
程序仅对目标工作台和技术支持系统两个固定地址放行内部证书错误。

十、WebView2
若启动时提示缺少 Microsoft Edge WebView2 Runtime，请运行同目录下的：
MicrosoftEdgeWebview2Setup.exe

十一、本地数据
恢复/历史数据库、WebView2 登录数据和脱敏日志位于：
%LocalAppData%\TechSupportBatchSubmitter
首次启动会自动生成 settings.json，可配置工作台地址、技术支持地址、默认提交/关闭间隔，
以及可选的版本提示信息。不要在 settings.json 中写入账号、密码、Cookie 或 Token。

十二、诊断包
遇到异常时，可在“运行日志”区域点击“导出诊断包”。
诊断包只包含程序版本、运行环境、配置摘要、当前 Excel 摘要和脱敏日志，不包含 Excel 原文件、
工单描述、账号密码、Cookie 或 Token。
