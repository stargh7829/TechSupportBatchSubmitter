# 技术支持批量提交工具 v1.4.0 产品化与猫主题设计

## 目标

本版把工具从“可自用的批量自动化程序”推进到“可分发、可诊断、可防误用的小产品”。功能侧优先解决 Excel 模板错误、使用人员误下源码包、异常定位困难三个问题；视觉侧在现有猫图标基础上强化猫主题，但不降低工作型界面的可读性。

## 范围

- 增强 Excel 模板校验：选择文件后输出可读的校验摘要，阻止重复表头、空数据、过长内容和明显非法编号等问题进入提交/关闭流程。
- 增加诊断包导出：收集脱敏日志、版本、配置摘要、本地历史库存在性和运行环境信息，生成 zip，便于用户反馈问题。
- 完善分发：构建脚本产出带版本号的便携包，并保留通用下载包名；文档强调普通用户下载 Release/便携包。
- 强化猫主题：标题区加入猫耳边框、状态脚印、提示框猫耳，不改变主表格密度和主要按钮层级。

## 不做

- 不保存账号、密码、Cookie 或平台会话。
- 不做自动在线更新；本版只为后续 Release/版本提示打基础。
- 不把平台固定地址完全外置；这需要更大范围的平台适配重构，放到后续版本。
- 不把界面改成卡通游戏风；可爱元素只用于标题、提示、状态和边框点缀。

## 验收

- `dotnet test -c Release` 通过。
- `scripts\build-portable.ps1` 生成 `技术支持批量提交工具-1.4.0-win-x64.zip` 和 `技术支持批量提交工具-win-x64.zip`。
- 启动后可看到猫主题标题、猫爪状态和诊断包按钮。
- 模板校验错误能在日志和提示中明确说明，且不会继续提交。
- 导出的诊断包不包含长数字、Cookie、Token、密码等敏感文本。
